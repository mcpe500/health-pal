## Features Overview

### Health Plan Generation:
- Users can generate personalized health plans based on their nutrition and activity data
- Plans include dietary recommendations, exercise suggestions, and lifestyle tips
- Integration with Gemini AI for intelligent plan generation
- Plans are stored and can be retrieved for future reference

### Reminders and Notifications:
- Users can schedule personalized health reminders
- Gemini AI generates contextual reminder messages based on user data
- Background scheduler automatically sends reminders via email
- Users can view their reminder history and schedule new reminders

## Technical Implementation Details

### Background Scheduler:
- Runs every 5 minutes to check for due reminders
- Queries database for pending reminders with scheduled time <= current time
- Sends email notifications using SMTP configuration
- Marks reminders as sent to prevent duplicate notifications

### Gemini Integration:
- Health plan generation uses user's nutrition and activity data as context
- Reminder text generation considers user goals, recent activity, and health plan
- Both features use the `gemini-pro` model for text generation
- Error handling for API failures and missing API keys

### Database Schema:
- `health_plans` table stores generated plans with JSON content
- `reminders` table stores scheduled reminders with status tracking
- Foreign key relationships maintain data integrity
