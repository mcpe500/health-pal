# 16. Implementing Data Visualization and HP Data Collection Features

## Goal
To enable users to visualize their health data and collect data from their mobile phones (HP).

## Key Requirements
*   **Data Visualization:**
    *   Display various health data points (steps, sitting time, nutrition, etc.) using charts.
    *   Allow users to select data types and date ranges for visualization.
*   **HP Data Collection:**
    *   Collect health data directly from the user's phone (not smartwatch).
    *   Request necessary permissions.
    *   Send collected data to the backend.
