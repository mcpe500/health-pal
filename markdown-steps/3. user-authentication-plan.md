# Detailed Plan for User Authentication and Account Deletion

## Goal
To implement user authentication using Google accounts only, and provide a secure account deletion mechanism via both the Flutter mobile application and a web-based backend interface.

## Key Requirements
*   **Authentication:** Google OAuth 2.0 based login (only Google Auth).
*   **Backend (Go/Gin):**
    *   Verify Google ID tokens.
    *   Store Google ID, email, name, and profile picture URL.
    *   Manage sessions using JWTs.
    *   Provide API endpoints for Flutter app for account deletion.
    *   Render HTML pages for web-based account deletion.
    *   Send OTPs via an email service for account deletion.
*   **Frontend (Flutter):**
    *   Integrate Google Sign-In.
    *   Communicate with backend for authentication and account deletion.
    *   Implement UI for account deletion with email and OTP.
*   **Account Deletion:** Soft delete users in the database, with email and OTP verification for both Flutter and web interfaces.

### High-Level Architecture Flow

```mermaid
graph TD
    subgraph Frontend
        A[Flutter App] --> B(Google Sign-In);
        B --> C{Get Google ID Token};
    end

    subgraph Backend_Go_Gin
        C --> D[API: /auth/google-login (POST)];
        D --> E{Verify Google Token & Extract User Info};
        E --> F{Store/Update User in MySQL DB};
        F --> G{Generate JWT};
        G --> H[Return JWT];
    end

    subgraph Authenticated Flow
        H --> I[Store JWT in Flutter App];
        I --> J[Authenticated API Calls];
        J --> K{JWT Validation Middleware};
        K --> L[Access Protected Resources];
    end

    subgraph Account Deletion Flow
        subgraph Flutter App
            M[User Initiates Deletion] --> N{Request OTP API};
            N --> O{Enter OTP UI};
        end

        subgraph Backend API (for Flutter)
            N --> P[API: /api/v1/delete-account/request-otp (POST)];
            P --> Q{Generate OTP & Send Email};
            O --> R[API: /api/v1/delete-account/verify-otp (POST)];
            R --> S{Verify OTP & Soft Delete User};
        end

        subgraph Backend Web Interface
            T[Admin/User Accesses Web Page] --> U[Web: /delete-account (GET)];
            U --> V{Render Email Input HTML};
            V --> W[User Submits Email];
            W --> X[Web: /delete-account (POST)];
            X --> Y{Generate OTP & Send Email};
            Y --> Z[Redirect to /delete-account/verify-otp (GET)];
            Z --> AA{Render OTP Input HTML};
            AA --> BB[User Submits OTP];
            BB --> CC[Web: /delete-account/verify-otp (POST)];
            CC --> DD{Verify OTP & Soft Delete User};
            DD --> EE[Render Result HTML];
        end
    end
```
