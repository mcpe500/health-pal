# Gin (Go) Backend Setup Guide

Gin is a high-performance, minimalist web framework for Go, ideal for building APIs and web applications.

## Why Choose Gin?
- **Pros:** High performance, simple API, easy to use
- **Cons:** Limited features out of the box
- **Best for:** High-performance APIs and web services

## Requirements
- Go 1.16 or above

## Installation

1. If you don’t have a `go.mod` file, create it:
  ```bash
  go mod init <module_name>
  ```
2. Download and install the Gin package:
  ```bash
  go get -u github.com/gin-gonic/gin
  ```

## Project Setup

1. Create your project folder and navigate into it:
  ```bash
  mkdir -p project && cd "$_"
  ```
2. Copy a starting template (e.g., `main.go`):
  ```bash
  curl https://raw.githubusercontent.com/gin-gonic/examples/master/basic/main.go > main.go
  ```

## Example `main.go`

**Basic Example:**
```go
package main

import "github.com/gin-gonic/gin"

func main() {
  router := gin.Default()
  router.GET("/ping", func(c *gin.Context) {
   c.JSON(200, gin.H{
    "message": "pong",
   })
  })
  router.Run() // listen and serve on 0.0.0.0:8080
}
```

**With `net/http` for status codes:**
```go
package main

import (
  "github.com/gin-gonic/gin"
  "net/http"
)

func main() {
  router := gin.Default()
  router.GET("/ping", func(c *gin.Context) {
   c.JSON(http.StatusOK, gin.H{
    "message": "pong",
   })
  })
  router.Run() // listen and serve on 0.0.0.0:8080
}
```

## Project Files

- `.env`: Environment variables (optional)
- `.gitignore`: Git ignore file for Go projects
- `main.go`: Main application file

## Install Dependencies

Run inside your project directory:
```bash
go mod tidy
```

## Running the Project

```bash
go run main.go
```
