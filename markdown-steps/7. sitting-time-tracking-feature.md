# 7. Implementing Sitting Time Tracking Feature

## Goal
To enable users to track their daily sitting time, allowing them to monitor their sedentary behavior.

## Key Requirements
*   **Backend (Go/Gin):**
    *   New database table to store sitting time data (user ID, date, sitting duration in minutes).
    *   API endpoints to record daily sitting time.
    *   API endpoints to retrieve sitting time history for a user.
*   **Frontend (Flutter):**
    *   UI to input daily sitting time.
    *   UI to display sitting time history.
    *   Integration with backend APIs for sitting time data.

### Detailed Plan Steps

#### Phase 1: Backend Implementation

1.  **Database Schema Update:**
    *   **Completed:** Created `migration/migrations/20250707120000-create-sitting-times.js` for a `sitting_times` table with `id`, `user_id`, `date`, `duration_minutes`, `created_at`, `updated_at`.
2.  **Implement Sitting Time Model:**
    *   **Completed:** Created `health_pal_backend/models/sitting_time.go` with a `SittingTime` struct, `SittingTimeResponse` struct, and CRUD methods.
3.  **Sitting Time Tracking Handlers:**
    *   **Completed:** Created `health_pal_backend/handlers/sitting_time.go` with:
        *   `RecordSittingTimeHandler`: To record daily sitting time for a user.
        *   `GetSittingTimeHistoryHandler`: To retrieve sitting time history for a user.
4.  **Routes:**
    *   **Completed:** Added new routes in `health_pal_backend/routes/routes.go` for sitting time tracking endpoints (e.g., `/api/v1/sitting-times`, `/api/v1/sitting-times/history`).

#### Phase 2: Frontend Implementation

1.  **API Client Update:**
    *   **Completed:** `health_pal_frontend/lib/utils/api_client.dart` is already set up to handle generic POST/GET requests, so no specific update was needed for sitting time tracking.
2.  **Sitting Time Tracking Service:**
    *   **Completed:** Created `health_pal_frontend/lib/services/sitting_time_service.dart` to encapsulate sitting time-related logic and API calls.
3.  **UI Implementation:**
    *   **Completed:** Updated `health_pal_frontend/lib/screens/home_screen.dart` to:
        *   Allow users to input their daily sitting time.
        *   Display a list of their sitting time history.

#### Phase 3: Documentation and Testing

1.  **Backend GoDoc Comments:** **Completed:** Added GoDoc comments to `health_pal_backend/models/sitting_time.go` and `health_pal_backend/handlers/sitting_time.go`.
2.  **Swagger Documentation:** **Completed:** Updated Swagger documentation for new sitting time tracking APIs by running `swag init`.
3.  **Testing:**
    *   Manually test sitting time recording and retrieval from Flutter app.
    *   Consider adding automated API tests for sitting time tracking in `health_pal_testing/api_tests/`.
    *   **Completed:** Ensured `db-migrate` target in the root `Makefile` will apply the new migration.
