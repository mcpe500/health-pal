# 5. Implementing Automated Tests

## Goal
To implement the automated API and E2E tests as defined in the `4. testing-plan.md`. This involves creating test files, writing test cases using Jest, Axios, and WebdriverIO, and ensuring the full stack works as expected.

## Phase 1: Test File Structure Setup

- **API Tests:**
  - Create `health_pal_testing/api_tests/config.js` for API configuration.
  - Create `health_pal_testing/api_tests/auth.test.js` for authentication API tests.
  - Create `health_pal_testing/api_tests/deletion.test.js` for account deletion API tests.
- **E2E Tests:**
  - Create `health_pal_testing/flutter_apk_tests/helpers/` for helper functions.
  - Create `health_pal_testing/flutter_apk_tests/auth_e2e.test.js` for authentication E2E tests.
  - Create `health_pal_testing/flutter_apk_tests/deletion_e2e.test.js` for account deletion E2E tests.

## Phase 2: API Test Implementation

- Implement positive and negative test cases for Google login and protected endpoints in `auth.test.js`.
- Implement positive and negative test cases for OTP request and verification for account deletion in `deletion.test.js`.

## Phase 3: E2E Test Implementation

- Implement the Google Login flow test in `auth_e2e.test.js`.
- Implement the account deletion flow test in `deletion_e2e.test.js`.

## Phase 4: Test Execution and Reporting

- Create a root `Makefile` to easily run all tests.
- Configure test reporters to generate JUnit XML reports in a root `test_reports/` directory.
