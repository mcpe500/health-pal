# 6. Implementing Step Tracking Feature

## Goal
To enable users to track their daily steps, allowing them to monitor their physical activity.

## Key Requirements
*   **Backend (Go/Gin):**
    *   New database table to store step data (user ID, date, steps count).
    *   API endpoints to record daily steps.
    *   API endpoints to retrieve step history for a user.
*   **Frontend (Flutter):**
    *   UI to input daily steps.
    *   UI to display step history.
    *   Integration with backend APIs for step data.

### Detailed Plan Steps

#### Phase 1: Backend Implementation

1.  **Update `health_pal_backend/go.mod`:**
    *   **Completed:** Added necessary dependencies: `google.golang.org/api/oauth2/v2`, `github.com/dgrijalva/jwt-go/v4`, `github.com/pquerna/otp`, `gopkg.in/mail.v2`, `gorm.io/gorm`, `gorm.io/driver/mysql`.
2.  **Implement Step Model:**
    *   **Completed:** Created `health_pal_backend/models/step.go` with a `Step` struct and CRUD methods.
3.  **Step Tracking Handlers:**
    *   **Completed:** Created `health_pal_backend/handlers/step.go` with:
        *   `RecordStepsHandler`: To record daily steps for a user.
        *   `GetStepsHistoryHandler`: To retrieve step history for a user.
4.  **Routes:**
    *   **Completed:** Added new routes in `health_pal_backend/routes/routes.go` for step tracking endpoints (e.g., `/api/v1/steps`, `/api/v1/steps/history`).

#### Phase 2: Frontend Implementation

1.  **API Client Update:**
    *   **Completed:** `health_pal_frontend/lib/utils/api_client.dart` is already set up to handle generic POST/GET requests, so no specific update was needed for step tracking.
2.  **Step Tracking Service:**
    *   **Completed:** Created `health_pal_frontend/lib/services/step_service.dart` to encapsulate step-related logic and API calls.
3.  **UI Implementation:**
    *   **Completed:** Updated `health_pal_frontend/lib/screens/home_screen.dart` to:
        *   Allow users to input their daily steps.
        *   Display a list of their step history.
    *   **Completed:** Added `intl` dependency to `health_pal_frontend/pubspec.yaml` for date formatting.

#### Phase 3: Documentation and Testing

1.  **Backend GoDoc Comments:** **Completed:** Added GoDoc comments to `health_pal_backend/models/step.go` and `health_pal_backend/handlers/step.go`.
2.  **Swagger Documentation:** **Completed:** Updated Swagger documentation for new step tracking APIs by running `swag init` after creating `models.StepResponse` and updating annotations in `handlers/step.go`.
3.  **Testing:**
    *   Manually test step recording and retrieval from Flutter app.
    *   Consider adding automated API tests for step tracking in `health_pal_testing/api_tests/`.
    *   **Completed:** Added `db-migrate` target to the root `Makefile` to run database migrations.
