# 8. Implementing Water Intake Tracking Feature

## Goal
To enable users to track their daily water intake, allowing them to monitor their hydration.

## Key Requirements
*   **Backend (Go/Gin):**
    *   New database table to store water intake data (user ID, date, amount in ml).
    *   API endpoints to record daily water intake.
    *   API endpoints to retrieve water intake history for a user.
*   **Frontend (Flutter):**
    *   UI to input daily water intake.
    *   UI to display water intake history.
    *   Integration with backend APIs for water intake data.

### Detailed Plan Steps

#### Phase 1: Backend Implementation

1.  **Database Schema Update:**
    *   **Completed:** Created `migration/migrations/20250708000134-create-water-intakes.js` for a `water_intakes` table with `id`, `user_id`, `date`, `amount_ml`, `created_at`, `updated_at`.
2.  **Implement Water Intake Model:**
    *   **Completed:** Created `health_pal_backend/models/water_intake.go` with a `WaterIntake` struct, `WaterIntakeResponse` struct, and CRUD methods.
3.  **Water Intake Tracking Handlers:**
    *   **Completed:** Created `health_pal_backend/handlers/water_intake.go` with:
        *   `RecordWaterIntakeHandler`: To record daily water intake for a user.
        *   `GetWaterIntakeHistoryHandler`: To retrieve water intake history for a user.
4.  **Routes:**
    *   **Completed:** Added new routes in `health_pal_backend/routes/routes.go` for water intake tracking endpoints (e.g., `/api/v1/water-intakes`, `/api/v1/water-intakes/history`).

#### Phase 2: Frontend Implementation

1.  **API Client Update:**
    *   Update `health_pal_frontend/lib/utils/api_client.dart` to include methods for water intake tracking APIs (if necessary, or reuse existing post/get).
2.  **Water Intake Tracking Service:**
    *   **Completed:** Created `health_pal_frontend/lib/services/water_intake_service.dart` to encapsulate water intake-related logic and API calls.
3.  **UI Implementation:**
    *   Update `health_pal_frontend/lib/screens/home_screen.dart` or create a new screen to:
        *   Allow users to input their daily water intake.
        *   Display a list or chart of their water intake history.

#### Phase 3: Documentation and Testing

1.  **Backend GoDoc Comments:** Add GoDoc comments to new Go files.
2.  **Swagger Documentation:** Update Swagger documentation for new water intake tracking APIs.
3.  **Testing:**
    *   Manually test water intake recording and retrieval from Flutter app.
    *   Consider adding automated API tests for water intake tracking in `health_pal_testing/api_tests/`.
