📋 Build Instructions

To build all platforms:

build.bat all

To build specific platform:

build.bat apk - Build Android APK

build.bat web - Build Web App

build.bat ios - Build iOS (simulation)

Local file access:

• APK files: ./builds/apk/

• Web files: ./builds/web/

• iOS info: ./builds/ios/

To clean builds:

build.bat clean
